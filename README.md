# 모션스튜디오 설치 파일

Claude와 대화로 광고 모션 영상을 기획·제작하고, 애프터이펙트처럼 직접 다듬는 데스크톱 프로그램이에요.
이 저장소에는 설치 파일과 자동 업데이트 정보만 있어요.

## 내려받기 (최신 버전)

[릴리즈 페이지](https://github.com/kanchoooo/motion-studio-releases/releases/latest)에서 컴퓨터에 맞는 파일을 받으세요.

| 컴퓨터 | 파일 |
|---|---|
| M칩 맥 (Apple Silicon) | `MotionStudio-<버전>-mac-arm64.dmg` |
| 인텔 맥 | `MotionStudio-<버전>-mac-x64.dmg` |
| 윈도우 | `MotionStudio-Setup-<버전>-x64.exe` |

- 맥: dmg를 열고 모션스튜디오를 「응용 프로그램」 폴더로 끌어 놓아요. 애플 공증을 받은 파일이에요.
- 윈도우: 설치 중 「Windows의 PC 보호」 창이 뜨면 「추가 정보 → 실행」을 눌러요.
- 처음 실행하면 환경 점검 화면에서 Claude 로그인, Claude Code 설치, 환경변수 설정을 도와줘요.
- 한 번 설치하면 새 버전은 앱을 열 때 자동으로 업데이트돼요.
